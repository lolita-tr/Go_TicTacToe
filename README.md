# Tic Tac Toe на Go с использованием Fx и Zap

Веб-приложение для игры в "Крестики-нолики" с поддержкой нескольких игровых сессий и аутентификацией пользователей.

## Основные технологии
- Язык: Go (Golang)
- Фреймворк: Uber FX (для dependency injection)
- База данных: PostgreSQL (хранение пользователей и игровой статистики)
- Аутентификация: JWT (JSON Web Tokens)
- Логирование: Zap
- HTTP-сервер: Стандартная библиотека net/http
- Фронтенд: HTML/JS + Go templates

## Функциональность
### Система аутентификации
- Регистрация новых пользователей (/signup)
- Вход в систему (/login)
- Обновление access/refresh токенов
- Middleware для проверки авторизации

## Игровые возможности
### Создание игры против бота (/new/bot)

- Создание игры против другого пользователя (/new/user)
- Совершение ходов в игре
- Просмотр текущего состояния доски
- Сброс игры
- Просмотр статистики игр


## API эндпоинты

### Публичные endpoints (не требуют авторизации)

| Метод | Путь                | Описание |
|----------|---------------------|----------|
| POST    | `/signup`           | 	Регистрация нового пользователя |
| POST    | `/login  `          |  Авторизация пользователя|
| POST   | `/refresh/access`   | 	Обновление access token |
| POST   | `/refresh/refresh`  |  Обновление refresh token  |

### Защищенные endpoints (требуют JWT в заголовке)
| Метод | Путь               | Описание                  |
|----------|--------------------|---------------------------|
| POST  | `/new/bot`         | Новая игра vs бот         |
| POST  | `/new/user`        | Новая игра vs игрок       |
| POST  | `/move/bot`        | Ход в игре с ботом        |
| POST  | `/move/users`      | Ход в мультиплеере        |
| GET   | `/board`           | Получить состояние доски  |
| POST  | `/reset`           | Сбросить игру             |
| GET | `/userinfo/id`           | Получить информацию о пользователе|
| GET   | `/games/current`   | Текущие игры              |
| GET   | `/game`   | 	Получить информацию об игре             |
| GET   | `/games/finished/id`   | Получить список завершенных игр|
| GET   | `/top/players`     | Получить топ игроков              |

