# Tic Tac Toe на Go с использованием Fx и Zap

Это веб-приложение реализует игру "Крестики-нолики" (Tic Tac Toe) с поддержкой нескольких игр одновременно. Приложение построено на языке Go с использованием:

- HTTP-сервера
- UUID для идентификации сессий игр
- [Uber Fx](https://github.com/uber-go/fx) — фреймворк для модульного запуска приложения
- [Zap](https://github.com/uber-go/zap) — логгирование
- Go templates + HTML/JS фронтенд

## Особенности

- Создание новой игры с уникальным идентификатором
- Хранение состояния каждой игры в памяти (с мьютексом)
- Ходы игрока и бота на стороне сервера
- Отображение игрового поля в браузере
- Логгирование состояния сервера


## API эндпоинты

| Метод | Путь | Описание |
|----------|---------|----------|
| GET    | /new  | Создание новой игры (возвращает game_id)  |
| GET    | /board?id= |  Получение текущего состояния игры   |
| POST   | /move?id= | Сделать ход (человек, затем бот)  |
| POST   | /reset?id= |  Сброс текущей игры  |
